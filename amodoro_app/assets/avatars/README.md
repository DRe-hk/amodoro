# Carpeta de Avatares Personalizados (`amodoro_app/assets/avatars/`)

Coloca aquí los archivos de imagen de los avatares (formatos soportados: `.png`, `.webp`, `.jpg`, `.svg`).

## Nombres de archivo esperados por ID de avatar

| ID en la app | Nombre de archivo recomendado | Descripción |
| :--- | :--- | :--- |
| `cat` | `cat.png` | Gatito naranja |
| `dog` | `dog.png` | Perrito |
| `rabbit` | `rabbit.png` | Conejito |
| `bear` | `bear.png` | Osito |
| `fox` | `fox.png` | Zorrito |
| `panda` | `panda.png` | Panda |
| `chick` | `chick.png` | Pollito |
| `gray_kitten` | `gray_kitten.png` | Gatito gris (Easter Egg *"zafiro"*) |

> Si subes archivos con otros nombres o menos/más avatares, avísame para actualizar la lista de IDs en `flat_avatar.dart`. Si algún archivo aún no está en la carpeta, el widget mostrará automáticamente su versión vectorial de respaldo para no romper la pantalla.
